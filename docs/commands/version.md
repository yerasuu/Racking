# rack version

## Purpose

Prints the version of this `rack` build. `rack --version` and `rack -V` do the same. It needs no server, token or config.

## Options

None.

## Examples

```sh
rack version
```

## Prints

`rack 0.1.2`.

## Exit codes

- 0 always

## MCP

None for `rack`. `racking-mcp --version` prints the version of the MCP server; `racking_agents` shows the version each agent reports.
