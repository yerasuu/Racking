# v0.1.3

First stable release; 0.1.1 and 0.1.2 were local test builds and were never published on GitHub. Includes everything of both, listed in `v0.1.1.md` and `v0.1.2.md`, plus:

## rack
- `guide.rs`: `COMMANDS` table (24 commands, name, summary, MCP tool, help text) drives `rack help`, `rack guide`, `rack guide COMMAND`, `--list`, `--changes`; one help file per command in `docs/commands/`, the overview in `docs/agent-guide.md`, all embedded with `include_str!`. Tests fail when a command, option or MCP tool is undocumented or the guide names a command that does not exist.
- `watch.rs`: `rack watch [--since N] [--once] [--timeout SECS]` prints one line (<= 200 chars) per new job, reconnects with backoff 1 to 30 s, one watcher per state file (`File::try_lock`); `rack inbox --unread [--count]`.
- `update`: stable and test channels; `rack update --pre`, `--check --pre`; `rack publish` fills the slot its version names and refuses a test build on a server without the test channel.
- `version.rs`: full SemVer 2.0.0 precedence (`0.1.4-1 < 0.1.4-2 < 0.1.4`), shared grammar table `testdata/versions.txt`.

## racking-server
- `GET /inbox?peek=1` lists without delivering.
- `dist.rs`: stable slot and test slot per target (`dist/<target>/`, `dist/pre/<target>/`); `GET /dist/pre/{target}/{file}`; manifest keeps its shape for stable and gains `prerelease`; build metadata (`+...`) in a version is refused with 400.

## racking-mcp
- `racking_guide` (optional `command`, `changes`); 17 tools.

## Build
- `release.rs` keys the notes gate off `CARGO_PKG_VERSION_MAJOR.MINOR.PATCH`, so `X.Y.Z-N` test builds use the notes of `X.Y.Z`.
- `rust-version = "1.89"` (`File::try_lock`); `license = "GPL-3.0-or-later"`; GitHub Actions CI in `.github/workflows/ci.yml`; `SECURITY.md`.
