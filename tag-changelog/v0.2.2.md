# v0.2.2

No protocol, config or API change. Adds installers for the clients.

## install
- `install/install.sh` (Linux) and `install/install.ps1` (Windows) install `rack` and `racking-mcp` for the current user: `~/.local/bin`, or `%LOCALAPPDATA%\Racking\bin` added to the user `PATH`. No root or administrator rights.
- Sources: a checkout's `target/release` (built with cargo when missing), `--from DIR` / `-From DIR`, or a GitHub release (`--version X.Y.Z` / `-Version X.Y.Z`, latest when run piped from `curl` or `irm`). Downloads are checked against the release's `SHA256SUMS` before anything is installed.
- `--dry-run` / `-DryRun` and `--uninstall` / `-Uninstall`; `rack.conf` is never touched. Windows keeps the replaced binary as `.old`, like `rack update`.

## ci
- `.github/workflows/release.yml`: on each stable `vX.Y.Z` tag, builds `rack` and `racking-mcp` on Linux (`rack-x86_64-unknown-linux-gnu.tar.gz`) and Windows (`rack-x86_64-pc-windows-msvc.zip`) and attaches them with `SHA256SUMS` to the GitHub release, whose notes are this directory's `vX.Y.Z.md`.
